## Domain 3.0: AI-assisted Security
 
### 3.1 Given a scenario, use AI-enabled tools to facilitate security tasks
 
#### Tools/Applications
 
- **IDE Plug-ins:** AI extensions in developer environments (GitHub Copilot, Cursor, JetBrains AI). Provide code completion, security suggestions, and vulnerability flagging inline.
- **Browser Plug-ins:** AI extensions in the browser for summarizing pages, extracting IOCs, phishing detection, and OSINT enrichment.
- **CLI Plug-ins:** AI assistants embedded in the terminal (Claude Code, GitHub Copilot CLI, Warp AI). Generate commands, explain errors, and script tasks from natural language.
- **Chatbots:** Web/API-based conversational assistants (ChatGPT, Claude, Gemini) used for research, drafting, code review, and log analysis.
- **Personal Assistants:** AI agents integrated with calendar, email, and files (Copilot for M365, Google Duet). Handle triage, drafting, and summarization.
#### Use Cases
 
- **Signature Matching:** Using AI to identify known malicious patterns in files, traffic, or logs faster and with fewer false negatives than static rules.
- **Code Quality and Linting:** AI review of code for bugs, style issues, and insecure patterns beyond what static linters catch.
- **Vulnerability Analysis:** AI-assisted triage of scanner output, CVE prioritization, and correlation of findings to exploit likelihood.
- **Automated Penetration Testing:** AI-driven tools that enumerate, exploit, and pivot (PentestGPT, PentestAI). Reduce manual effort in recon and payload crafting.
- **Anomaly Detection:** ML models baseline normal behavior and flag deviations in traffic, user activity, or endpoints.
- **Pattern Recognition:** Identifying recurring TTPs, campaigns, or IOCs across large data volumes.
- **Incident Management:** AI summarizes tickets, suggests remediation steps, and drafts postmortems.
- **Threat Modeling:** AI helps generate STRIDE/PASTA threat lists from architecture diagrams or code.
- **Fraud Detection:** ML models score transactions and behaviors in real time for fraud indicators.
- **Translation:** Converting foreign-language threat intel, malware strings, or dark-web chatter into analyst-readable text.
- **Summarization:** Condensing long reports, RFCs, breach notifications, or log files into actionable briefs.
### 3.2 Explain how AI enables or enhances attack vectors
 
#### AI-Generated Content (Deepfake)
 
- **Deepfake:** Synthetic audio/video/image content generated by AI to convincingly mimic real people or events.
  * **Impersonation:** Voice-cloned CFO calls demanding wire transfers, cloned faces on video calls, spoofed executive emails.
  * **Misinformation:** False content spread without intent to deceive (sincerely believed).
  * **Disinformation:** False content spread deliberately to deceive, manipulate, or influence.
- **Adversarial Networks:** Attackers use GAN-style setups to generate inputs (evasive malware, adversarial images, phishing pages) that defeat defensive ML models.
- **Reconnaissance:** AI automates OSINT collection, target profiling, exposed-asset discovery, and dark-web scraping.
- **Social Engineering:** LLMs draft convincing, grammatically clean, personalized phishing/vishing/smishing at scale in any language.
- **Obfuscation:** AI rewrites malicious code, encodes payloads, and mutates strings to evade signature-based detection.
- **Automated Data Correlation:** AI stitches together leaked data from breaches, social media, and public records to build detailed victim profiles for targeted attacks.
#### Automated Attack Generation
 
- **Attack Vector Discovery:** AI scans targets and suggests likely exploitable paths based on tech stack, versions, and misconfigurations.
- **Payloads:** AI generates or mutates exploit payloads to evade WAFs, EDR, and antivirus.
- **Malware:** AI-written or AI-mutated malware (polymorphic samples, LLM-generated droppers, deepfake-based lures).
- **Honeypot:** Attackers use AI to detect honeypots by analyzing response patterns, latency, and inconsistencies before engaging.
- **DDoS:** AI coordinates botnets, adapts attack traffic patterns in real time, and picks optimal target endpoints to overwhelm defenses.
### 3.3 Given a scenario, use AI to automate security tasks
 
#### Scripting Tools
 
- **Low-code:** Platforms requiring minimal code (Power Automate, n8n, Zapier) where AI helps design and generate workflows.
- **No-code:** Fully visual/prompt-driven platforms (Make, drag-and-drop SOAR) where AI generates the workflow from a natural language description.
- **Document Synthesis and Summarization:** AI compiles multiple sources (policies, tickets, reports) into a single document or condenses long docs into briefs. Speeds up compliance work.
- **Incident Response Ticket Management:** AI auto-classifies, deduplicates, enriches, and prioritizes SOC/IT tickets. Drafts initial response and next steps.
#### Change Management
 
- **AI-assisted Approvals:** AI reviews change requests, checks against policy, flags risky changes, and routes for the right approver.
- **Automated Deployment/Rollback:** AI monitors deployments, detects regressions or anomalies, and triggers rollback without human intervention.
- **AI Agents:** Autonomous systems that plan multi-step tasks, call tools/APIs, and act toward a goal. Used for automated triage, remediation, threat hunting.
#### CI/CD
 
- **Code Scanning:** AI-augmented SAST/DAST finds bugs and vulnerabilities in code and running apps during the pipeline.
- **Software Composition Analysis (SCA):** AI-enhanced scanning of third-party dependencies for known CVEs and license issues.
- **Unit Testing:** AI generates and maintains unit tests based on code changes.
- **Regression Testing:** AI identifies which existing tests need to run based on the change diff, reducing test suite runtime.
- **Model Testing:** Automated tests for ML models covering accuracy, fairness, drift, and adversarial robustness before release.
- **Automated Deployment/Rollback:** AI-driven CI/CD gates that promote or roll back builds based on real-time metrics and security signals.
